# v1.1.1 verification

Automated checks use Chromium with software rendering in the development environment. They are not physical-phone benchmarks.

- Camera regression tests cover stable jump framing, eased look-ahead, falling anticipation, stationary ledge inspection, inverted gravity and reset.
- TypeScript production build and Vitest physics/project/generator tests.
- Generated route replay for rooms 1–100 of seed `first-root`, plus alternate-seed difficulty-ceiling coverage.
- Browser creator paint/select/property/copy/paste, save/reload, export/import, campaign unlock/practice UI, and generated room 100.
- Landscape 844 × 390 browser layout: 4:3 and 16:9 video ratios, unchanged full-width touch surface, custom control layout flow, pressed-state feedback and locked-ability indicators.
- Offline production reload/playtest and worker generation.
- Actual waiting service worker update: explicit activation, unsaved editor draft, selected room and control mode preserved.

Not established: frame rate or memory use on a 2 GB Android phone; full human campaign playthrough/balance; Safari/iOS installation behavior; every seed/index; adversarial anti-cheat. No such guarantees should be inferred from passing tests.
